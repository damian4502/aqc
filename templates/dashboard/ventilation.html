Ventilation (ACH)

Finds falling segments automatically, then fits an exponential clearance curve. The decay constant is an air-change estimate when the parameter behaves like a tracer with no indoor source during the drop — typically CO₂ after people leave. On other parameters it is only a relative clearance rate.

Higher ACH means the excess above the fitted baseline falls faster. Compare rooms on the same parameter.

A segment starts at a peak (or at the beginning of the window if the series is already falling) and ends when the value climbs again. Baseline percentile is only used to decide which peaks are tall enough. The fit estimates its own baseline. Leave min. rise empty to set it from the spread of the series. Max baseline, if set, drops a decay whose fitted floor is above that value. Leave it empty for no limit. Min baseline does the same from below. Lowest in period sets that floor from the smallest resampled reading of each parameter in the selected range, across the selected rooms, and ignores the number. A floor slightly under that reading is still kept. Keep gaps avoids inventing samples between readings.
